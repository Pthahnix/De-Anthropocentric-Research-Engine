DARE v4 - Pass 3

Whole-system scientific-graph expansion: direction, evidence acquisition, knowledge structuring, and experiment design are now folded into the same two executable node types. Still not final.

Pass 3 thesis

Only two executable node types.
Tactic = bounded scientific algorithm.
SOP = single reusable cognitive transform.
Compression is semantic, not numeric.
Safe duplicates merge. Method-specific operators remain specialized. Similar output names alone are not enough to merge.
Three destinations for old nodes.
Scientific cognition -> graph.
Generic budget/checkpoint/iteration control -> runtime. Scientific evidence saturation remains an SOP.
Paper/web/subagent plumbing -> delete.

Progress

Pass 3 specifically audits north-star-crystallization, knowledge-acquisition, knowledge-structuring, experiment-execution, engine-core, context-management, and ara-from-context.
