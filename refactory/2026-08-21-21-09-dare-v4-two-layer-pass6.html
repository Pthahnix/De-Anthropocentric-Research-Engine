Pass 6 tactic compression

Only merge when input schema can be parameterized, the core transformation is shared, and output semantics can be preserved as modes.
rank-candidates3→1 TACTIC
prioritize-research-gaps + multi-criteria-decision + narrow-research-direction

Modes: gap-prioritization, direction-selection, mcda-best-choice, full-ranking, category-sorting, non-compensatory-screening, rapid-triage, stakeholder-weighted

The three tactics share the same criteria→score→aggregate kernel. Their differences are object schema and optional preconditions, not a different scientific transformation. Pairwise active comparison and portfolio subset optimization remain separate tactics because their state/update logic differs.

map-validity-envelope2→1 TACTIC
validity-envelope-analysis + boundary-stress-test

Modes: systematic-perturbation, boundary-value-stress, critical-case

Deep-insight and stress-test both encoded validity-envelope mapping with the same output and nearly identical breakpoint/envelope operations. Boundary stress is an extreme-value sampling policy over the same workflow, not a separate algorithm.

explore-dimensional-space2→1 TACTIC
morphological-search + map-dimensional-research-space

Modes: morphological-generation, research-space-mapping, gap-mapping

Both tactics operate on the same dimension×value combinatorial representation and share enumeration plus compatibility checking. Research-space mapping adds occupancy/gap analysis as a downstream mode; it does not require a distinct kernel.

adversarial-deliberation2→1 TACTIC
adversarial-debate + steelman-validation

Modes: critic-defender-judge, courtroom, winner-stress, resurrection-advocacy, criteria-interrogation, stakeholder-objection, counter-thesis

Both tactics use the same critique→defense→adjudication kernel. Steel-manning differs mainly in which object/perspective is assigned to the roles, so preserving it as a mode removes a human organizational distinction without removing adversarial scientific reasoning.

analyze-constraints-readiness3→1 TACTIC
feasibility-readiness + analyze-direction-obstacles + analyze-research-constraints

Modes: obstacle-triage, readiness-assessment, resource-envelope, causal-constraint-analysis, maturation-path

All three answer the same scientific control question—what prevents this research target from succeeding and what changes would remove the blocker—at different depths and object scopes. Quantitative resource gaps and causal conflict analysis remain optional operators inside the common tactic.

crystallize-north-star [inline]1→1 TACTIC
synthesize-north-star

Modes: direct SOP tail

The Pass 5 tactic only called one SOP and added no independent branching/iteration kernel, so the wrapper is removed and crystallize-north-star becomes an optional tail of decompose-research-goal.
